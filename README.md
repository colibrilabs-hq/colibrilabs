# Colibri Labs

Sitio estático de una sola página para Colibri Labs.

## Estructura

```text
.
├── assets
│   ├── css
│   │   └── styles.css
│   ├── images
│   │   └── favicon.svg
│   └── js
│       └── main.js
├── index.html
└── README.md
```

## Uso local

Abre `index.html` directamente en el navegador o sirve la carpeta con cualquier
servidor web estático.
